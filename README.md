# Travel Price Aggregator

## Концепция
Модуль агрегации и сравнения цен на авиабилеты и отели.

## Технологический стек
- Frontend: React 18, Vite, Tailwind CSS
- Backend: Node.js, Express
- БД: PostgreSQL
- API: Aviasales Travelpayouts, Booking.com

## Структура папок
- client/ — фронтенд
- server/ — бэкенд
- docs/ — документация
- .github/ — шаблоны Issue и PR

## Установка
1. Клонировать репозиторий
2. Скопировать .env.example в .env
3. npm install
4. npm run dev# travel-price-aggregator
